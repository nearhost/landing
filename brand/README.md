# Nearhost brand files

Generated by `npm run logo` from the same geometry and colours the site uses.

| File                         | Use                                                                                 |
| ---------------------------- | ----------------------------------------------------------------------------------- |
| `nearhost-logo-dark.png`     | Square logo, 1024px. The default avatar for GitHub, npm and social profiles.        |
| `nearhost-logo-dark-500.png` | The same at 500px, the size GitHub recommends for organisation avatars.             |
| `nearhost-logo-beacon.png`   | Square logo on the accent colour, for app icons and places that need more presence. |
| `nearhost-logo-*.svg`        | Vector versions of the squares.                                                     |
| `nearhost-mark-on-dark.svg`  | The bare mark on a transparent background, for dark surfaces.                       |
| `nearhost-mark-on-light.svg` | The bare mark for light surfaces: ink arch, accent dot.                             |

The squares are full bleed with no rounded corners. GitHub and app stores apply their own rounding.

Colours: ground `#0F1210`, beacon `#D6F26B`, text `#ECEFE8`, ink `#1B1F1C`.
